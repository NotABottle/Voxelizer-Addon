# Voxelizer-Addon
Voxelizer is a Blender addon for creating voxel-based assets easily within your scenes.

### Showcase Footage

### Description
Voxelizer is a Blender addon designed to streamline the creation of voxel-based assets directly within production scenes. It provides a one-click workflow to convert static or rigged meshes into voxelized representations, automatically organizing generated assets into structured collections for easier iteration and integration into downstream engines.

The tool is built to reduce friction between DCC workflows and real-time voxel systems, enabling rapid prototyping of voxel-based art and gameplay systems.

### Key Features:
One-click voxelization of static and rigged meshes
Automatic scene organization via generated collections
Artist-friendly UI for fast iteration
Designed for integration with real-time voxel rendering pipelines

### Impact:
Reduces voxel asset generation workflow from ~30 minutes of manual setup to ~1 minute.

### How to use
1. Select either a rigged or static mesh.
2. Tick the box corresponding to the type of mesh you are attempting to voxelize.
3. Click Voxelize.
4. New collections will be automatically created for organizational purposes.
